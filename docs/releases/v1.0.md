- NASM source editor with syntax highlighting, file opening and saving, and an included example program.
- Build assembly programs with NASM and GNU ld, then start, stop, restart, or step through individual instructions with GDB.
- Highlight the current source line and next instruction in memory.
- Display 64-bit registers, signed or unsigned decimal register parts, and CPU flags, with indicators for changed values.
- Inspect real process memory with separate colors for `.text`, `.rodata`, `.data`, and `.bss`, variable labels, address tooltips, and changed-byte highlights.
- View 80 bytes of stack memory that follow RSP as the program executes.
- Animate values transferred by MOV and added by ADD between source, registers, and memory.
