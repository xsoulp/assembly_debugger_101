# Installable preview

[Download ASM101 0.1.0 signed release APK](https://github.com/xsoulp/assembly_debugger_101/raw/refs/heads/android/android/apk/asm101-0.1.0-release.apk)

Requires ARM64 Android 9+. No root or emulation. This is an initial preview;
native execution has not yet been validated on an accessible physical Android
device. Check [`../README.md`](../README.md) for features and limitations.

The APK is signed and has app debugging disabled. `SHA256SUMS` verifies the file.
For automated hardware tests, build the debug app and instrumentation APK from
source as described in the parent README.
